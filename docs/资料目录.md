# 资料目录

所有 JSON Lines 文件使用 UTF-8 编码。data/catalog.json 保存字段、行数、主键及校验和；原始资料不含分析结果。

## households

文件 data/households.jsonl；120 条；主键 household_id。字段：household_id, risk_tier, cohort, enrolled_at。

## cases

文件 data/cases.jsonl；360 条；主键 case_id。字段：case_id, household_id, opened_at, closed_at, kind。

## events

文件 data/events.jsonl；1400 条；主键 event_id。字段：event_id, case_id, household_id, modality, kind, occurred_at, received_at, status。

## outages

文件 data/outages.jsonl；20 条；主键 outage_id。字段：outage_id, household_id, start, end, kind。

## consents

文件 data/consents.jsonl；160 条；主键 consent_id。字段：consent_id, household_id, modality, valid_from, valid_to, withdrawn_at。

## service_slots

文件 data/service_slots.jsonl；12 条；主键 slot_id。字段：slot_id, start, end, capacity, staff。

## service_policy

文件 data/service_policy.jsonl；3 条；主键 policy_id。字段：policy_id, risk_tier, max_wait_hours, minimum_confirmed_share。

## confirmed

文件 data/confirmed.jsonl；2 条；主键 confirm_id。字段：confirm_id, household_id, slot_id, confirmed_at, cancelled_at。

## requests

文件 data/requests.jsonl；18 条；主键 request_id。字段：request_id, household_id, slot_id, requested_at。
