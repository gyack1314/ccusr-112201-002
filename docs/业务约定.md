# 业务约定

case_id 标识同一事项，同 case_id 的触达不计多个独立成功。household_id 为分析和分配单位。occurred_at 与 received_at 分开；事项在 opened_at 后72小时且明确关闭或退出时成熟。consents 只对列出的 modality 和期间有效，撤回不删除历史已完成触达。service_slots.capacity 为同时承接家庭数，confirmed 占用至结束或明确取消。risk_tier 是既定服务分层。

所有记录为本地合成资料；缺失值为 JSON null。资料中的候选操作不是已确认操作。编号仅标识对象，不携带优先级。历史截点以当时已获知事实判断，不以后来的更正冒充当时已知。
